# Legacy CLI

The original Aspira CLI prototype. Preserved for reference during the rewrite to a Next.js + FastAPI web platform.

## Run

```bash
cd legacy/cli
python main.py
```

## Status

No longer actively maintained. The web rewrite lives under `frontend/` and `backend/` at the repo root. The MySQL schema is being extended via Alembic migrations in `backend/alembic/`.
